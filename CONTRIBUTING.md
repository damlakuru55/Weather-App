# Contributing

## Development

1. Open the project in your editor.
2. Make a focused change to weather search, data rendering, or the interface.
3. Test successful searches and invalid-location states in a modern browser.
4. Verify the responsive layout at different viewport sizes.

## Quality Checklist

- Keep asynchronous requests handled without freezing the interface.
- Show a clear state when a location cannot be found.
- Handle unavailable weather data gracefully.
- Avoid exposing API credentials in client-side source.
- Test the main search flow after JavaScript changes.

## Pull Requests

Explain the user-facing change and include the testing steps used to verify it.
