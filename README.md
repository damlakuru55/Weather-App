# Weather App

A weather application designed to display weather information through a simple and responsive interface.

## Features

* Search for locations
* Display weather information
* Clean weather dashboard
* Responsive layout
* User-friendly interface

## Technologies

* HTML5
* CSS3
* JavaScript

## Purpose

This project was created to practice API integration, asynchronous JavaScript, and dynamic data rendering.
